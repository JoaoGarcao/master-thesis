Conflict-Free Replicated Data Types (CRDTs) are a key abstraction for modern distributed systems, enabling concurrent
updates across multiple replicas while guaranteeing Strong Eventual Consistency without centralized coordination. Despite
these guarantees, designing CRDTs correctly remains challenging, and formal verification helps prevent errors that
compromise data integrity. Automated verification tools based on Satisfiability Modulo Theories (SMT) solvers, such as
VeriFx, enable rapid validation of algebraic convergence properties, but struggle with recursive definitions, inductive
properties, and global state invariants. Deductive platforms such as Why3 overcome these limitations through explicit
contracts and invariants, at the cost of a much higher specification effort.

This dissertation addresses this trade-off with an integrated framework for the modular, formal development of CRDTs,
built around a dedicated language for specifying state-based and operation-based CRDTs. Once type-checked, a single
specification is automatically compiled into both VeriFx, targeting automated proof of convergence properties via the Z3
solver, and WhyML, targeting deductive verification of semantic correctness and global invariants, which keeps the two
verification efforts consistent. The framework was evaluated on ten CRDTs, including counters, sets, a generic map, and
the Replicated Growable Array (RGA), reducing the manual specification effort while producing idiomatic code for both
targets. The automated VeriFx proof of RGA times out, leaving its convergence unverified. With inductive lemmas, the
deductive Why3 proof still shows that every pair of its operations commutes on the element sets, and that every pair
except two insertions commutes on the full state. The two backends therefore complement each other, with automation
keeping the effort low for most CRDTs and deduction reaching further where automation stops, which illustrates the benefit
of pairing automated and deductive verification rather than relying on either in isolation.
